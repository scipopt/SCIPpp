# SCIP++

C++ wrapper around SCIP's C API: library target `ScipPP`, namespace `scippp`.
Distributed via Conan Center; API docs are generated by Doxygen and published to GitHub Pages.

## Hard constraints

* **C++17 only.** It is the minimum standard for consumers (`CMakeLists.txt`, `_min_cppstd` in `conanfile.py`), and
  CI builds with GCC 11, AppleClang and MSVC and runs clang-tidy 14. No concepts, ranges, `<format>`, `std::span`,
  etc.
* Public API lives in `include/scippp/*.hpp`. The project follows SemVer, so do not break it: deprecate
  (`@deprecated since X.Y.Z: Use #foo() instead`) instead of removing or changing signatures.
* `Model` owns the `SCIP*` (if it created it) and releases all vars/conss in its d'tor. `Var` and other wrappers are
  non-owning handles.
* Every SCIP call inside `Model` goes through `m_scipCallWrapper(...)`, never `SCIP_CALL`.

## Generated files: do not edit by hand

* `include/scippp/parameters.hpp`: output of `utils/gen_constexpr_parameters.cpp`.
* `include/scippp/solving_statistics.hpp`: output of `utils/extract_solvingstats.py`.

Both carry an `updated for SCIP X.Y.Z` header comment. See the `update-scip` skill.

## Conventions

* Formatting: `.clang-format` (WebKit), checked in CI with clang-format 17.
* Naming: enforced by `.clang-tidy` (`camelBack` functions/variables, `m_` private members, `UPPER_CASE` constants,
  `CamelCase` types, `lower_case` namespaces).
* Every public symbol has a Doxygen block with `@since X.Y.Z` (the next release version). Write `%SCIP` in Doxygen
  text so Doxygen does not autolink it.
* Getters are `[[nodiscard]]`. Member functions that do not change the C++ object are `const`, even if they change
  the underlying SCIP state (see PR40).
* Every user-visible change adds an entry under `## [Unreleased]` in `changelog.md` (Keep a Changelog, format
  `- [PRnn](https://github.com/scipopt/SCIPpp/pull/nn) ...`).
* Features that are part of the documented API also get a short example in `readme.md`.

## Layout

* `source/`: implementation. `source/version.cpp.in` is configured by CMake.
* `test/`: Boost.Test, one `test_<topic>.cpp` per area with `BOOST_AUTO_TEST_SUITE`. `test/examples.cpp` holds
  small end-to-end models (e.g. knapsack).
* `utils/`: code generators, built only with `BUILD_UTILS=ON` / `-o with_utils=True`.
* `build/`, `html/`, `CMakeUserPresets.json`: generated, git-ignored.

## Build and test (Conan)

```bash
conan install -o with_tests=True --build=missing .       # add -pr debug for build/Debug
cmake --preset conan-release .
cmake --build build/Release --target tests
build/Release/test/tests                                 # --run_test=Var/GetSolVal for a single case
```

Without Conan: `cmake -DBUILD_TESTS=ON . && make tests && ./test/tests` (needs SCIP and Boost via `find_package`).
